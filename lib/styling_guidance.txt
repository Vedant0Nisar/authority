# 9️⃣ BUTTON SYSTEM

## Primary Button (CTA – Example: “Login”, “Book Now”)

* Height → 52
* Border Radius → 16
* Background → Green Gradient
* Text Color → White
* Font → 16 / 600
* Horizontal Padding → 24

### States

* Normal → Full gradient
* Pressed → Slightly darker (5% darker)
* Disabled →

  * Dark → `#334155`

* 1.5px border
* Border color = Gradient Start
* Text color = Gradient Start
